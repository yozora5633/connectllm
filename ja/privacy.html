ConnectLLM プライバシーポリシー

最終更新日: 2026年9月4日

1. 基本方針

1.　開発者は，ConnectLLM（以下「本アプリ」という．）の利用に関して，利用者の個人情報を収集しない．

2.　本アプリは，利用者の行動を追跡せず，広告識別子を利用せず，解析基盤を組み込んでいない．

3.　開発者は，本アプリのためのサーバーを有しない．会話・添付・設定は，すべて利用者の端末内に保存される．

4.　本アプリは，利用者が自ら設定した接続先（LLM サーバー又はクラウドの LLM サービス）と通信するための道具である．接続先へ送られた内容の取扱いは，その接続先の運営者の方針による．

5.　前各項にかかわらず，利用者が Apple との診断情報の共有を有効にしている場合，開発者は，Apple を通じて，個人を特定しない範囲の障害情報（クラッシュログ）を受け取ることがある．

2. 開発者が収集しない情報

開発者は，次の各号に掲げる情報を含め，利用者に関する一切の情報を収集しない．

一　氏名，住所，電話番号，メールアドレスその他の連絡先

二　会話の内容，添付した画像・ファイル及びシステムプロンプト

三　接続先の URL 及び利用者が設定した API キー

四　位置情報

五　広告識別子（IDFA）その他の端末識別子

六　利用状況の統計又は解析情報

3. 端末内に保存される情報

1.　本アプリは，次の各号に掲げる情報を利用者の端末内に保存する．

一　会話の本文，添付した画像・ファイル及び生成された画像

二　接続先の URL，モデル名，システムプロンプトその他の設定

三　API キー（端末の Keychain（暗号化領域）にのみ保存し，接続先ごとに分けて保持する）

四　道具（ウェブ検索・ページ取得・画像生成）が端末の外と通信した記録（宛先と送信内容の要約）

2.　会話のデータベースは，端末のバックアップ（iCloud バックアップ及びパソコンへのバックアップ）の対象から外している．端末を交換する場合は，本アプリの書き出し機能で移す．

3.　開発者は，第1項の情報を取得することも閲覧することもできない．

4. 外部への送信が発生する場合

次の各号に掲げる場合に限り，端末の外への通信が発生する．

1.　利用者が設定した接続先へ，利用者の操作に基づき，次のデータが送信される．

一　会話の本文（過去のやり取りを含む），システムプロンプト及び添付した画像・ファイルの内容

二　利用者が設定した API キー（接続先が求める場合）

三　道具を使う設定にしている場合，道具の実行結果（検索結果，取得したページの本文等）

2.　接続先が利用者の管理下のネットワーク（自宅の LAN 等）にある場合，通信はそのネットワークの中で完結する．接続先がクラウドのサービスである場合，送信された内容の保存・利用の方針はその事業者の規約による．本アプリは，接続先がどちらであるかを画面に常に表示し，接続先を切り替えて過去の会話を送る前に確認を求める．

3.　利用者が設定で道具を有効にした場合に限り，次の通信が発生する．いずれも既定では無効である．

一　ウェブ検索　検索語が検索エンジン（DuckDuckGo）へ送信される．接続先が Moonshot 又は Anthropic の場合は，検索はその事業者の側で行われ，検索語は本アプリから検索エンジンへ送られない

二　ページ取得　モデルが指定した URL のページを端末が取得する．端末内及びローカルネットワークの宛先，並びに会話の内容を運ぶ形の URL は取得しない

三　画像生成　モデルが会話から起こした指示文が，利用者が設定した画像生成の接続先へ送信される．接続先が会話用と別で，かつ利用者の管理下のネットワーク外である場合は，送信前にその指示文を示して確認を求める

4.　音声入力において，端末が端末内の音声認識に対応していない場合又は対応していない言語の場合，OS の音声認識機能が音声を Apple のサーバーで処理することがある．

5.　利用者が会話を書き出し，その保存先又は共有相手に iCloud Drive 等のクラウドを自ら選んだ場合は，その選択先へデータが複製される．書き出しの際にパスフレーズを設定すると，書き出したファイルは暗号化される．

6.　本アプリは，利用者の接続先以外へ会話の内容を送信しない．接続先へ送られた後の内容の取扱いについて，開発者は関与せず，責任を負わない．

5. 端末の機能の利用目的

本アプリは，次の各号に掲げる目的のために端末の機能を利用する．利用の可否は，利用者が端末の設定において変更することができる．

一　ローカルネットワーク　利用者のネットワーク上にある LLM サーバーへ接続するため

二　マイク及び音声認識　音声でメッセージを入力するため．音声は文字起こしにだけ使われ，接続先へは文字のみが送られる

三　写真　添付する画像・動画を選ぶため．本アプリは写真ライブラリ全体にはアクセスせず，利用者が選んだ項目のみを受け取る

四　Face ID 等の生体認証　アプリロックのため．認証の情報は端末内で処理され，本アプリはこれを取得しない

五　通知　応答の生成が完了したことを知らせるため．通知に会話の内容及び表題は含めない

六　バックグラウンド処理　アプリを閉じた後も応答の生成を続けるため

6. 第三者への提供

開発者は，利用者に関する情報を取得しないため，これを第三者に提供することはない．第4条の接続先への送信は，利用者が自ら接続先を設定し，自らの操作で行うものであり，開発者による提供には当たらない．

7. 広告

本アプリに広告は含まれていない．

8. 言語

本方針は日本語を正文とする．他の言語に翻訳して提供する場合において，日本語版と他の言語版との間に相違があるときは，日本語版の解釈が優先する．

開発者は，本方針の内容を変更することがある．変更した場合は，本ページを更新し，最終更新日を改める．
