ConnectLLM とは

ConnectLLM は，自分で用意した LLM サーバーやクラウドの LLM サービスに iPhone から接続して会話する iOS アプリである．自宅のパソコンで動かしている Ollama や LM Studio にも，OpenAI・Anthropic・Moonshot などのクラウドにも，同じ画面で接続できる．

できること

接続先を複数登録して切り替えながら会話できる．画像やテキストファイルを添付して送れ，音声で入力できる．応答は Markdown として整形して表示し，コードブロックはそのままコピーできる．

設定で有効にした場合に限り，ウェブ検索・ページ取得・画像生成をモデルに使わせることができる．いま話している相手がどこにいるか（自分の管理下のネットワークか，中継か，クラウドか）は画面に常に表示される．

データの扱い

会話・添付・設定は，すべてあなたの端末の中に保存される．開発者のサーバーは存在せず，開発者が内容を受け取ることも見ることもない．

会話の内容は，あなたが設定した接続先にだけ送られる．クラウドのサービスに接続する場合は，その事業者の規約と料金があなたに適用される．
